<h1>Tags HTML</h1>

Las etiquetas HTML son bloques de código que dan formato, funcionalidad y estructura al contenido de las páginas web. Estos fragmentos sirven como indicadores o instrucciones para que un navegador muestre de forma adecuada la información contenida en tus documentos.

Cada entrada de esta guía reúne lo mismo: la definición de la etiqueta, el código que la usa y el resultado que estás viendo ahora mismo en tu navegador.

Texto y encabezados

<h1> … <h6>

Las etiquetas h1, h2, h3, h4, h5 y h6 crean encabezados de distintos niveles en una página web. Cada una tiene un tamaño de fuente y un nivel de importancia específico: h1 es el encabezado más importante y h6 el menos importante. Los buscadores y los lectores de pantalla usan estos niveles para entender el orden del documento.

<h1>Este es el Título Principal</h1>
<h2>Subtítulo Importante</h2>
<h3>Subtítulo Menos Importante</h3>
<h4>Subtítulo de Nivel 4</h4>
<h5>Subtítulo de Nivel 5</h5>
<h6>Subtítulo de Nivel 6</h6>

<p>

La etiqueta p define un párrafo dentro de un documento web. El contenido que va entre la etiqueta de apertura y la de cierre forma un párrafo separado. Por defecto, los navegadores añaden un espacio vertical antes y después de cada párrafo.

<p>Este es un párrafo de ejemplo.</p>
<p>Este es otro párrafo.</p>

Este es un párrafo de ejemplo.

Este es otro párrafo.

<br>

La etiqueta br inserta un salto de línea dentro del texto y desplaza el resto hacia una nueva línea dentro del mismo párrafo. No tiene contenido visible y no necesita etiqueta de cierre.

<p>Este es un ejemplo<br>de salto de línea en un párrafo.</p>

Este es un ejemplo
de salto de línea en un párrafo.

<wbr>

La etiqueta wbr (word break opportunity) marca un punto donde el navegador puede cortar una palabra si el espacio no alcanza. No fuerza el salto: solo ofrece ese lugar para hacerlo. Es útil con direcciones web o palabras muy extensas.

<p>Este es un texto con una palabra extremadamente<wbr>larga.</p>

Este es un texto con una palabra extremadamentelarga.

Prueba a reducir el ancho de la ventana: la palabra se corta justo donde indica wbr, y sin esa marca se saldría del contenedor.

<pre>

La etiqueta pre representa texto preformateado: el contenido se muestra exactamente como está escrito, con sus espacios en blanco, sangrías y saltos de línea. Es útil para mostrar código fuente o cualquier texto cuya estructura visual importa.

<pre>
function saludar() {
  console.log("¡Hola, mundo!");
}
</pre>
function saludar() {
  console.log("¡Hola, mundo!");
}

Fíjate en que los espacios del interior no se comprimen: el código aparece con el mismo formato que en el archivo.

<blockquote>

La etiqueta blockquote representa un bloque de texto que es la cita o el extracto de otro recurso, como un libro, un artículo o una entrevista. El contenido se muestra sangrado a ambos lados para distinguirlo del texto circundante.

<blockquote>
  <p>Este es el texto citado. Puede ser una cita larga o corta.</p>
</blockquote>

Este es el texto citado. Puede ser una cita larga o corta.

<small>

La etiqueta small define un fragmento de texto que se presenta en un tamaño menor que el texto circundante. Se usa para contenido menos relevante: letra pequeña, créditos o comentarios.

<p>Este es un breve ejemplo de la etiqueta:
   <small>texto pequeño en comparación</small> con el resto de la línea.</p>

Este es un breve ejemplo de la etiqueta: texto pequeño en comparación con el resto de la línea.

<u>

La etiqueta u se usaba tradicionalmente para subrayar texto y así señalar que era un enlace o que tenía importancia. En HTML5 el elemento se redefinó y se desaconseja subrayar contenido que no sea un enlace o una marca propia: existen elementos más apropiados para eso.

<p>El texto <u>subrayado</u> ya no significa que sea un enlace.</p>

El texto subrayado ya no significa que sea un enlace.

<mark>

La etiqueta mark resalta fragmentos de texto dentro del documento para destacar información relevante. Los navegadores suelen pintar ese fondo de amarillo, de modo que la parte marcada se distingue de la línea completa.

<p>Este es un ejemplo de texto <mark>resaltado</mark> con la etiqueta mark.</p>

Este es un ejemplo de texto resaltado con la etiqueta mark.

<ins>

La etiqueta ins marca el contenido que ha sido insertado en el documento respecto de su versión anterior. Representa una adición o un cambio nuevo y, por defecto, se muestra subrayado.

<p>Este texto fue <del>eliminado</del> y este texto fue <ins>insertado</ins>.</p>

Este texto fue eliminado y este texto fue insertado.

<del>

La etiqueta del marca el contenido eliminado respecto de una versión anterior del documento. Por defecto se muestra tachado, de modo que el lector vea qué se quitó.

<p>La versión anterior indicaba un crecimiento del
   <del>12%</del>, corregido a 10% tras revisar los datos.</p>

La versión anterior indicaba un crecimiento del 12%, corregido a 10% tras revisar los datos.

<sub>

La etiqueta sub representa texto como subíndice: se coloca ligeramente por debajo de la línea base. Se usa en contextos científicos, matemáticos y técnicos para fórmulas químicas, ecuaciones y notación matemática.

<p>El agua se representa como H<sub>2</sub>O.</p>

El agua se representa como H2O.

<sup>

La etiqueta sup representa texto como superíndice: se coloca ligeramente por encima de la línea base. Es útil en matemáticas y ciencias para exponentes y potencias.

<p>El área de un círculo es A = πr<sup>2</sup>, donde r es el radio.</p>

El área de un círculo es A = πr2, donde r es el radio.

<time>

La etiqueta time representa fechas y horas en un formato estándar. Marca la información temporal de forma semántica, lo que facilita el trabajo de los lectores de pantalla y de los buscadores. El atributo datetime lleva la fecha en formato ISO 8601, legible para la máquina, mientras que el texto interior se muestra en el formato que prefieras para las personas.

<p>La fecha de publicación de este artículo es
   <time datetime="2023-10-30">30 de octubre de 2023</time>.</p>

La fecha de publicación de este artículo es 30 de octubre de 2023.

<data>

La etiqueta data incorpora un valor específico asociado a un contenido, como una cifra o una fecha, y lo liga a un valor legible para la máquina mediante el atributo value. Aporta semántica al documento y mejora la accesibilidad, porque las tecnologías de asistencia pueden interpretar el dato.

<p>La temperatura actual es <data value="25">25°C</data>.</p>

La temperatura actual es 25°C.

<dfn>

La etiqueta dfn marca la instancia de un término que se está definiendo o explicando dentro del texto. Indica de forma semántica que ese término tiene una definición específica en el contexto de la página.

<p>El <dfn>HTML</dfn> es el lenguaje de marcado que da
   estructura a las páginas web.</p>

El HTML es el lenguaje de marcado que da estructura a las páginas web.

<code>

La etiqueta code marca fragmentos de código dentro del documento. Indica que ese contenido es código fuente y normalmente se muestra en una fuente monoespaciada para distinguirlo del texto normal. Su uso es habitual en varios contextos:

  • Mostrar ejemplos de código fuente.
  • Resaltar comandos o instrucciones en tutoriales técnicos.
  • Presentar código en documentación técnica.
  • Marcar datos o valores literales que deben copiarse tal cual.
  • Indicar nombres de variables, funciones o identificadores.
<p>Para imprimir un mensaje en JavaScript, utiliza
   <code>console.log('Hola, mundo');</code>.</p>

Para imprimir un mensaje en JavaScript, utiliza console.log('Hola, mundo');.

<samp>

La etiqueta samp representa la salida de un programa o el mensaje que devuelve una aplicación. El texto se muestra en monoespaciada, igual que se vería en una terminal.

<p>El instalador devuelve: <samp>Error 5: Access is denied</samp>.</p>

El instalador devuelve: Error 5: Access is denied.

<kbd>

La etiqueta kbd indica que el texto que contiene es una entrada de teclado, un comando o un atajo.

<p>Pulsa <kbd>Ctrl</kbd> + <kbd>S</kbd> para guardar.</p>

Pulsa Ctrl + S para guardar.

Estructura semántica

<main>

La etiqueta main marca el contenido principal de un documento. Se introdujo en HTML5 para mejorar la accesibilidad y la estructura de la página: indica claramente cuál es el contenido principal, lo que beneficia a los buscadores, a los lectores de pantalla y a quien mantiene el sitio. Solo debe haber un elemento main visible por documento.

<main>
  <h1>Título de la página</h1>
  <p>Este es el contenido principal: la información más relevante.</p>
</main>

En esta página, todo lo que estás leyendo está dentro de un único main.

<section>

La etiqueta section define una sección temática o agrupa contenido relacionado, dividiendo el documento en bloques lógicos. Cada sección suele llevar un encabezado que describe su contenido. Facilita la navegación, la accesibilidad y el estilo con CSS.

<section>
  <h4>Recientes</h4>
  <p>Contenido agrupado por tema.</p>
</section>

Recientes

Contenido agrupado por tema.

<article>

La etiqueta article marca contenido independiente y autónomo: puede existir por sí mismo y es lógicamente independiente del resto del documento. Puede ser una noticia, una entrada de blog o una publicación en un foro. Usarlo ayuda a estructurar la página de forma semántica, lo que beneficia a los buscadores y a los lectores de pantalla.

<article>
  <h4>Entrada independiente</h4>
  <p>Puede publicarse por sí misma, como un post o una noticia.</p>
</article>

Entrada independiente

Puede publicarse por sí misma, como un post o una noticia.

<header>

La etiqueta header define una sección de encabezado con información introductoria o de navegación: logotipo, título de la página, enlaces principales u otros elementos que se quieran destacar en la parte superior.

<header>
  <h4>Noticias de hoy</h4>
  <p>Fecha, autor y navegación de la sección.</p>
</header>

Noticias de hoy

Fecha, autor y navegación de la sección.

El encabezado de esta página es la franja superior con el logotipo.

<footer>

La etiqueta footer define una sección de pie de página con información relevante pero situada al final del documento: contacto, derechos de autor, enlaces relacionados, referencias o atribución.

<footer>
  <p>Créditos, enlaces y derechos de autor.</p>
</footer>

Créditos, enlaces y derechos de autor.

El pie de esta página está al final y contiene los créditos del trabajo.

<aside>

La etiqueta aside marca contenido secundario o complementario: información tangencial como notas aclaratorias, barras laterales o enlaces relacionados que, aunque guardan relación con el contenido principal, no son esenciales para comprenderlo. Ayuda a estructurar la página y facilita su lectura para las personas y para los buscadores.

<aside>
  <p>Nota al margen: contenido complementario.</p>
</aside>

Nota al margen: contenido complementario.

<nav>

La etiqueta nav marca una sección de navegación. Contiene enlaces que permiten moverse por el sitio: secciones importantes, menús o barras de navegación.

<nav aria-label="Demostración">
  <a href="#inicio">Inicio</a>
  <a href="#s-texto">Texto</a>
  <a href="#s-tablas">Tablas</a>
</nav>
Inicio Texto Tablas

El índice de la izquierda de esta página también es un nav.

<figure>

La etiqueta figure agrupa contenido relacionado, como imágenes, gráficos o diagramas, junto con su descripción. Permite asociar la imagen a su leyenda, lo que es especialmente útil para la accesibilidad y para dar contexto al contenido visual.

<figure>
  <img src="paisaje.jpg" alt="Un lago entre montañas">
  <figcaption>Esta es una imagen que ilustra un hermoso paisaje natural.</figcaption>
</figure>

<figcaption>

La etiqueta figcaption proporciona la descripción o leyenda del contenido agrupado dentro de una etiqueta figure. Da contexto al contenido visual y siempre vive en el interior de figure.

<figure>
  <img src="favicon.png" alt="Logotipo de HTML5">
  <figcaption>Logotipo de HTML5.</figcaption>
</figure>

<div>

La etiqueta div (abreviatura de division) crea un contenedor genérico o bloque de división. No aporta significado ni formato por sí misma: sirve para agrupar elementos y organizar el diseño de la página mediante CSS o JavaScript.

<div class="caja">
  <p>Contenido agrupado dentro de un bloque.</p>
</div>

Contenido agrupado dentro de un bloque.

Multimedia y gráficos

<img>

La etiqueta img inserta imágenes en el documento: fotografías, gráficos o iconos. Requiere el atributo src, que indica la ruta de la imagen. El atributo alt describe la imagen para quienes no pueden verla, y width y height fijan sus dimensiones en píxeles.

<img src="anatomia-img.webp"
     alt="Partes de la etiqueta img">

<svg>

La etiqueta svg inserta gráficos vectoriales. Al estar definidos por vectores y no por píxeles, escalan sin perder calidad al cambiar de tamaño. Se definen con sintaxis XML y pueden contener formas, líneas, texto y otras primitivas.

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="#E0451B" />
</svg>

Tablas

<caption>

La etiqueta caption da un título a la tabla. Se coloca justo después de la etiqueta de apertura, de modo que el título queda asociado a la tabla y es visible para todo el que acceda a ella.

<table>
  <caption>Lista de precios de productos</caption>
  <tbody>
    <tr>
      <th>Producto</th>
      <th>Precio</th>
    </tr>
    <tr>
      <td>Lámpara LED</td>
      <td>$20.00</td>
    </tr>
    <tr>
      <td>Silla de oficina</td>
      <td>$45.00</td>
    </tr>
  </tbody>
</table>

<colgroup>

La etiqueta colgroup agrupa un conjunto de columnas de la tabla para aplicarles propiedades comunes, como el ancho o el color de fondo, en un solo lugar y sin repetirlos fila por fila.

<table>
  <colgroup>
    <col style="background-color:#F3E3B8">
    <col span="2" style="background-color:#D7E3F4">
  </colgroup>
  <tbody>
    <tr>
      <td>Columna 1</td>
      <td>Columna 2</td>
      <td>Columna 3</td>
    </tr>
  </tbody>
</table>

<col>

La etiqueta col define propiedades para una columna individual de la tabla. Se declara dentro de colgroup y permite fijar ancho, color de fondo u otros estilos para esa columna.

<table>
  <colgroup>
    <col style="background-color:#D7E3F4">
    <col style="background-color:#DCEBD8">
    <col style="background-color:#F3E3B8">
  </colgroup>
  <tbody>
    <tr>
      <td>Columna 1</td>
      <td>Columna 2</td>
      <td>Columna 3</td>
    </tr>
  </tbody>
</table>

<thead>

La etiqueta thead define la sección de encabezado de una tabla: agrupa las filas que contienen los títulos de las columnas y separa visualmente ese bloque del resto del contenido.

<table>
  <thead>
    <tr>
      <th>Columna 1</th>
      <th>Columna 2</th>
      <th>Columna 3</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1A</td>
      <td>1B</td>
      <td>1C</td>
    </tr>
  </tbody>
</table>

<tbody>

La etiqueta tbody define la sección del cuerpo de una tabla: agrupa las filas que contienen el contenido principal, excluyendo los encabezados del thead y los totales del tfoot.

<table>
  <thead>
    <tr>
      <th>Nombre</th>
      <th>Edad</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>María</td>
      <td>25</td>
    </tr>
    <tr>
      <td>Juan</td>
      <td>30</td>
    </tr>
  </tbody>
</table>
Nombre Edad
María 25
Juan 30

<tfoot>

La etiqueta tfoot define la sección del pie de una tabla: agrupa las filas con información resumida, totales u otros datos relevantes, y se declara después de tbody pero antes del cierre de la tabla.

<table>
  <thead>
    <tr>
      <th>Producto</th>
      <th>Precio</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Producto A</td>
      <td>$20.00</td>
    </tr>
    <tr>
      <td>Producto B</td>
      <td>$130.00</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Total</td>
      <td>$150.00</td>
    </tr>
  </tfoot>
</table>
Producto Precio
Producto A $20.00
Producto B $130.00
Total $150.00

La etiqueta tfoot es opcional, pero su uso deja la estructura semántica clara. Es común combinarla con thead y tbody para organizar el contenido tabular.
