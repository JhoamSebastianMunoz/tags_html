# Tags HTML

Página web estática educativa que documenta y ejemplifica las principales etiquetas de **HTML5**, mostrando para cada una su uso, características y un ejemplo práctico renderizado en el navegador.

## Contenido

El documento recorre, entre otras, las siguientes etiquetas:

- **Encabezados y texto:** `h1`–`h6`, `p`, `br`, `wbr`, `pre`, `blockquote`, `small`, `u`, `mark`, `ins`, `del`, `sub`, `sup`, `dfn`, `code`, `samp`, `kbd`, `time`, `data`
- **Estructura semántica:** `main`, `section`, `article`, `header`, `footer`, `aside`, `nav`, `div`, `figure`, `figcaption`
- **Multimedia y gráficos:** `img`, `svg`
- **Tablas:** `caption`, `colgroup`, `col`, `thead`, `tbody`, `tfoot`

## Uso

No requiere instalación ni servidor. Abre el archivo `index.html` directamente en cualquier navegador web:

```powershell
Start-Process "index.html"
```

## Estilos

Los estilos se definen en `tags_html.css` e incluyen:

- Fondo `beige` y tipografía `sans-serif` para todos los elementos.
- Efecto de zoom (`scale`) sobre imágenes con la clase `.imagen` y `.imagen_grande` al pasar el cursor.
